# Aditya Gaur - Portfolio

Personal portfolio website for Aditya Gaur, Full-Stack Developer.

This is a static website written in plain HTML, CSS and JavaScript. It is not a Next.js or React project, so there is no build step and no npm dependencies to install.

## What is included

- `index.html` - page structure: hero, Selected Work, About, Stack, Resume, Contact, and the two case-study views (`#work-gati`, `#work-biteloop`).
- `css/styles.css` - all styling, typography, animation and responsive rules.
- `js/main.js` - loader, dot portrait, background effect, scroll sequence, navigation and case-study views.
- `js/portrait-data.js` - precomputed dot map of the portrait (regenerated by the tool below).
- `assets/images/` - portrait fallback image, resume preview, and the portrait cut-out used to build the dot map.
- `assets/resume/Aditya-Gaur-Resume.pdf` - the downloadable resume.
- `tools/build_portrait_data.py` - regenerates `js/portrait-data.js` from the cut-out.
- `package.json` - the `npm start` command.

## Requirements

- Node.js LTS from https://nodejs.org (used for `npm start`). Python 3 is optional.
- An internet connection. GSAP (the animation library) and Google Fonts load from CDNs. Without them the page still shows its content, but the scroll animations and custom fonts will not run.

## Run it on Windows with VS Code

1. Unzip `aditya-gaur-portfolio.zip` (right-click, Extract All).
2. In VS Code choose File > Open Folder and select the `aditya-gaur-portfolio` folder.
3. Open the terminal with Terminal > New Terminal.
4. Type `npm start` and press Enter.
5. Open http://localhost:3000 in your browser. Stop the server with Ctrl+C.

If PowerShell says that running scripts is disabled, type `npm.cmd start` instead, or use Command Prompt.

Without Node.js, you can run `py -m http.server 3000` (or `python -m http.server 3000`) from the project folder and open http://localhost:3000.

## Dependencies

There are none to install. `package.json` lists no dependencies, so there is no `node_modules` folder and no lockfile. `npm start` downloads the small `serve` web server on demand. When you add real dependencies later, run `npm install` to create a lockfile.

## Environment variables

None are needed. The site contains no secrets, API keys or credentials, so there is no `.env` file.

## Editing

- Text and links: `index.html`. Search for the text you want to change.
- Colours and layout: `css/styles.css`. Colour variables are at the top, under `:root`.
- Animation behaviour and timing: `js/main.js`.
- Portrait dots: after changing the cut-out, run `pip install pillow numpy` and then `python tools/build_portrait_data.py`.
- New resume: replace `assets/resume/Aditya-Gaur-Resume.pdf` and `assets/images/resume-preview.jpg`, keeping the same names, or update the references in `index.html` and `js/main.js`.
- Project screenshots: none are included yet. Add real screenshots of GATI and BiteLoop to replace the placeholder panels in the Selected Work cards and case studies.

## Checks

`npm run check` syntax-checks the JavaScript files.

## Deploying

Upload the folder to any static host, such as Vercel, Netlify or GitHub Pages. On Vercel choose "Other" as the framework and leave the build command empty.

## Notes

- Project links open the live site in a new tab. The live sites are not embedded.
